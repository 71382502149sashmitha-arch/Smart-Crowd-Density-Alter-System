25EE256 - Sensor & Instrumentation Case Study #2

1. System Description

The Smart Crowd Density Alert System monitors foot-traffic through an access corridor using an HC-SR04 ultrasonic distance sensor to measure target proximity and a PIR motion sensor to verify occupant presence.

2. State Machine & Alert Tiers

Tier Level Crowd Count Green LED (D8) Yellow LED (D9) Red LED (D10) Buzzer (D11) Diagnostic Action
Tier 1: Normal < 5 HIGH LOW LOW noTone() Safe passage; optimal density
Tier 2: Warning 5 to 9 LOW HIGH LOW noTone() Approaching venue capacity
Tier 3: Critical ≥ 10 LOW LOW HIGH tone(1000Hz) OVERCROWDED! Evacuation / Diversion

3. Physics & Sensing Formulas

  • Ultrasonic Time-of-Flight: distance (cm) = (duration × 0.0343) / 2 where sound speed is 343 m/s in air.
  • Entry Registration: Counts when distance < 50 cm and unlatches once distance ≥ 50 cm with a 200ms debounce.
  • Execution Period: Main loop executes every 300 ms.

4. Web Serial Physical Bridge

You can flash this Arduino code directly onto a real Arduino Uno via the Arduino IDE, connect your board to this PC via USB, and click "Connect USB Serial" at 9600 baud. The web application will automatically switch to hardware parsing mode!
